# bitstream 与实测

本文给出发布的这份 bitstream 跑多快、在片上占多少资源，用来判断一次运行的耗时是否合理。

**文档模式**：实测数。

## 时钟

板上的 50 MHz 晶振接进 MMCM，分出功能时钟 50 MHz 与它的两倍频 100 MHz。片上互联与两路
DDR3 之间是异步的，MIG 那两个时钟各约 133 MHz。

综合与布局布线按 19 ns 收敛，比板上 20 ns 的时钟周期紧 5%。布线后最差建立裕量 +0.220 ns、
最差保持裕量 +0.030 ns，863,660 个端点全部满足。

## 一轮要多少拍

拍数由板上 CPU 自己报，秒数按 50 MHz 折算。

| 一轮 | 拍数 | 秒 |
| - | -: | -: |
| decode 一步（一个 token） | 12,184,243 | 0.24 |
| prefill 一轮（64 个 token） | 54,863,944 | 1.10 |

decode 折算 4.1 token/s。

## 片上资源

器件是 `xc7k480tffg1156-2L`。综合完与布线完各报一次，布线后的 LUT 比综合后少，是打包进
SLICE 时合并掉的那些。

| 资源 | 综合后 | 布线后 | 器件总量 | 布线后占比 |
| - | -: | -: | -: | -: |
| LUT | 272,057 | 256,676 | 298,600 | 85.96% |
| 　其中作查找表 | 241,483 | 226,547 | 298,600 | 75.87% |
| 　其中作分布式存储 | 30,574 | 30,129 | 108,600 | 27.74% |
| 触发器 | 188,862 | 187,770 | 597,200 | 31.44% |
| SLICE | | 73,916 | 74,650 | 99.02% |
| BRAM（按 RAMB36 折算） | 483.5 | 483.5 | 955 | 50.63% |
| 　RAMB36 | 470 | 470 | 955 | 49.21% |
| 　RAMB18 | 27 | 27 | 1,910 | 1.41% |
| DSP48 | 980 | 980 | 1,920 | 51.04% |
| 引脚 | | 242 | 400 | 60.50% |

SLICE 占到 99%，意味着片上可编程逻辑已经用满，再加东西要先腾地方。
